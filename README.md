# 渡海 / Across the Sea

山东大学翻译学院「蓝色创想·以语为桥」跨文化传播创新实践大赛 · B 赛道（数字传播）参赛作品。

一条 3 分钟动画短片，和一个可以读懂它、续写它、把它讲给更多人听的交互网页。

- **在线观看**：<https://caohua13.github.io/duhai-across-the-sea/>
- **完整版正片**：网页内直接播放 3′00″（`assets/video/duhai_full_720.mp4`）
- **说明文档**：`作品说明_创新转化.pdf` / `.docx`
- **AI 创作说明**：`AI创作说明.pdf` / `.docx` / `.md`（逐项交代哪些环节用了 AI、用了什么工具、哪里必须人来把关）

## 页面内容（11 个板块）

0. 十幕读片：全屏一幕一幕读完整片
1. 方法论：一条短片怎么变成一件可参与的作品
2. 成片 + 交互陪看：点场次跳到画面，播放时自动高亮当前段
3. 海那边：把片中的问题交给观众，接力墙
4. 故事：10 张场次卡
5. 时间轴 + 情绪曲线
6. 八仙：这件法宝在今天对应什么
7. 多声部：中·英·法·俄四句台词与原声
8. 无障碍：一条字幕的十秒钟、盲文点阵、高对比模式
9. 声音：全片波形 + 十句人声逐句可听
10. 工坊：译写工作台、八仙双语卡、港口故事卡、渡海十二物
11. 社会价值：落地场景与五种角色分工

## 本地打开

- 双击 `index.html`（离线可用）；
- 或双击 `一键打开网页链接.bat`，得到 `http://127.0.0.1:8899/index.html` 的本地链接（同 WiFi 设备也可访问）。

> 页面为纯前端实现：无后端、无账号、不上传；观众回答只保存在浏览器本地。
