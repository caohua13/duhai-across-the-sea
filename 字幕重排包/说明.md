# 渡海 · 字幕重排包（直接可用）

本文件夹是"8 小时救急"的字幕重做材料。目录：

```
字幕重排包/
├── 渡海_中英双语.srt    ← 23 条正式字幕，每条"中文行 + 英文行"
├── 渡海_字幕表.csv      ← 同内容表格（UTF-8 BOM，Excel 直接打开不乱码）
├── 渡海_字幕表.xlsx     ← 同上，已设列宽与冻结首行
└── 说明.md              ← 本文件：怎么导入、哪些行需要人工再核
```

> 字幕库里共 27 条记录，其中 4 条是**内部标注**（画面标题卡「各显神通」、两处「（海浪声，无台词）」、一处「（书页翻动，无台词）」），不导出为字幕文件——它们是对画面的说明，不该出现在屏幕上。

---

## 一、快速导入（剪映 / CapCut）

1. 打开原片 → 新建项目 → 导入视频。
2. 先隐藏原片自带字幕（或把画面下方约 15% 裁掉，若原字幕是烧录的跑不出字幕条，就用裁剪）。
3. 「文本 → 本地字幕 → 导入字幕」选择 `渡海_中英双语.srt`，会自动铺到时间轴上。
4. 全局检查：双击任一条字幕 → 样式改为「双语」，中文设为上行、英文设为下行；字号建议中文 7–8、英文 6。
5. 导出 1920×1080 / H.264 / 30fps。

其他软件（Premiere、Final Cut、DaVinci）同理：直接导入 SRT，再套双语样式。

## 二、这份字幕相对原片的 4 个关键改动

| 原片问题 | 本包的处理 |
|---|---|
| 全片基本只有中文行 | 每条都配了英文行（上行中文、下行英文） |
| 2′31″ 法语台词配了 **俄语**原文 | 法语台词 = `Chez moi aussi, la mer raconte des histoires.`，排在 02:31–02:36 |
| 2′38″ 俄语台词配了 **法语**原文 | 俄语台词 = `Давайте поделимся нашими историями.`，排在 02:36–02:41 |
| 笑声、"呃"、"一路顺风" 被做成字幕 | 已全部移除，非台词语气词不再上屏 |

另外补上了原片没有做出来的两处关键句（按剧本）：`02:42` 起的两段结尾旁白，以及 `02:31` 之前一句“在我的家乡”的过渡句。

## 三、导入后需要人工再核的 5 处

1. **说话人**：02:31（法语）与 02:36（俄语）两句必须在能看清对应说话人的画面上；原片这两句都落在低头看手机/远景上，建议把这两条字幕挪到相应的近景，或把画面裁切到说话人。
2. **对白人名**：铁拐李、汉钟离、吕洞宾、何仙姑、英语青年、法语青年、俄语青年——如后期配音有人名变化，请同步改。
3. **英文校审**：英文行按剧本译法整理，建议找英语专业同学通读一遍，重点看 `八位仙人，八种渡海方式？`（Eight immortals, eight ways across?）与 `跨过海的不只是货物`（More than goods crossed the sea.）两句的语气。
4. **语速匹配**：若你的成片旁白比 SRT 里的时间段更慢/更快，只需拖动字幕块两端对齐，不要改文字。
5. **结尾**：178.2–180.4s 为原片的黑场，本包不为其配字幕；改片时请把黑场换成海面淡出，音轨同时对齐。

---

## 四、如果时间只剩 1 小时（最低限度版）

不需要全部重排，只做下面 **3 条**，也能把最致命的失分救回来：

1. 把原片所有**只有中文行**的字幕，逐条补上英文行（至少覆盖对白：00:22、00:25、00:45、00:50、01:36、02:31、02:38）。
2. 把 **02:31 / 02:38** 两条法/俄字幕的原文互换回来（或直接删掉外语原文，只留"中文＋英文"），消除错位。
3. 删掉 00:33 前后的 `哈哈哈`、`呃`、`一路顺风` 三处非台词字幕。

仅做这 3 处，评审最可能挑的"多语言没做出来"问题就基本解决了。
